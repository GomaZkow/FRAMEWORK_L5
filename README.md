Документация API для управления бассейнами
Базовый URL

http://localhost:3000
Эндпоинты
Получение данных

GET /pool - Получить список всех бассейнов
GET /pool/:id - Получить бассейн по ID (числовой параметр)
Создание и обновление

POST /pool - Создать новый бассейн (требует тело запроса в формате JSON)
PUT /pool/:id - Полное обновление бассейна (требует ID и тело запроса)
PATCH /pool/:id - Частичное обновление бассейна (требует ID и тело запроса)
Удаление

DELETE /pool/:id - Удалить бассейн по ID (числовой параметр)
Коды ответов

    200 - Успешный запрос

    201 - Успешное создание

    400 - Неверный запрос (некорректные данные)

    404 - Бассейн не найден

    500 - Ошибка сервера

Установка

    Установите зависимости: npm install

    Запустите сервер: npm start

Сервер будет доступен по адресу: http://localhost:3000
